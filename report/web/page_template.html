Architecture

The MAC unit rides the pipeline

The MAC unit's two internal registers line up with the core's EX/MEM and MEM/WB registers, so a mac moves down the pipeline like any other instruction and writes back in WB.

Memory map

Design choices
  • AccumulatorA dedicated 64-bit register keeps full precision for 32×32 products with only two register-file read ports.
  • SaturationSigned MACs clamp to the INT64 limits and set a sticky flag; rdacc.q15 turns Q30 into Q15 in one instruction.
  • HazardsOnly a consumer placed directly after a MAC result waits one cycle, exactly like a load; the value then comes from WB.

Performance

Same filter, two instruction sets

A 16-tap Q15 low-pass FIR over 128 samples, measured with the core's cycle counters. All four versions produce the same bit-exact output.

One mac replaces the six-instruction 64-bit multiply-accumulate sequence, and rdacc.q15 replaces a 14-instruction shift-and-saturate routine.

Notes from the build

What the numbers taught

28.9 nscore critical path

The multiply that sets the clock

The pipelined MAC unit is not the slowest path. It runs from WB forwarding, through the forwarding mux and the single-cycle RV32M multiplier on four DSP blocks, into EX/MEM; 18.9 ns of it is routing. Pipelining mul the way the MAC unit already is would be the next timing fix.

−7,109gates saved

One multiplier instead of three

Separate 64-bit products for MUL, MULH, MULHSU and MULHU, plus a register file with a reset, made the first core 22,412 gates. One shared 33×33 multiplier and a reset-free register file in LUT-RAM brought it to 15,303 with identical results.

79 %of MAC gates

Where the Booth area goes

The Booth multiplier is most of the stand-alone MAC unit and the routing hot spot on the die. Yosys' own Booth and Wallace-tree generator saves 21 % of the gates but keeps the same 127-level depth, because the ripple-carry final adder sets it.

1.59× → 2.67×looped → unrolled

What's next

Post-increment loads and a hardware loop would let looped DSP code reach unrolled speed. After that: a parallel-prefix adder for the Booth multiplier, a pipelined RV32M multiplier, block-RAM memories and a run on a real ECP5 board.
